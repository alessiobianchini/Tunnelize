## Architecture & Infrastructure
- **Server Component (`Tunnelize`):** A .NET (C#, ASP.NET Core) application acting as a WebSocket/HTTP proxy server. It manages tunnel connections and forwards traffic.
- **Client Component (`TunnelizeClient`):** A Node.js CLI tool using the `ws` package to establish a persistent WebSocket connection to the server and forward local HTTP requests.
- **Infrastructure:** Designed to run locally or be hosted (e.g., Azure App Service for the server). Uses `pnpm` for Node.js package management and standard `dotnet` CLI for the backend.
